About this demo: “Select”

This is the select demo: a presentation where a URL parameter picks which chapters or slides are shown, and every other marked section is hidden.

The bar along the top is Simplemenu. Every one of these demos loads it, because it is the quickest way to see which chapters a parameter left standing.

What you have been looking at

The portfolio above is all of the work, because you arrived without a parameter. Name a tag or a name in the URL and only those chapters are left — every other marked chapter is removed once the presentation starts.

The markup

Selecting means the parameter picks what is shown. It can only choose between sections it can recognise, so everything it should be able to hide has to be marked. Each chapter here has a name and a tag.

<section data-name="Identity" data-tag="branding"> ... </section>
<section data-name="Websites" data-tag="web">     ... </section>
<section data-name="Books"    data-tag="print">   ... </section>
<section data-name="Posters"  data-tag="print">   ... </section>

The title slide and this chapter have data-tag="keep" instead, which leaves them out of the filters. They are shown whatever you include.

The config

Nothing. Tags and names are in the markup, and mode is already "select" by default, so this deck configures nothing at all.

The one thing you would add is a group, which is next.

Try it

  • ?t=web — the websites only
  • ?t=print — two chapters share that tag
  • ?t=web,print — either one
  • ?n=identity — by name instead
  • demo-select.html — everything again

A group

A group is a set of tags and/or names under one word, so the link can be short and you can change what it means later.

tagteam: {
    groups: {
        pitch: {
            tags: ["branding", "web"]
        }
    }
}

?g=pitch shows the identity work and the websites.

Unhide, the other way round

Selecting makes the parameter be the presentation, so everything it should be able to hide has to be marked.

Unhiding is the opposite: only the extras are marked, and a parameter reveals them without touching anything else. See the unhide demo.
